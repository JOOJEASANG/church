등록된 공지

📖 이번 주 설교

설교 제목·본문·유튜브 URL과 (선택) 재생 구간을 입력하면 메인 페이지 말씀 탭에 표시됩니다

📍 재생 구간 (선택) — 풀영상에서 설교 부분만 자르고 싶을 때만 입력. 비우면 처음부터 끝까지 재생.

이번 주 설교로 저장: 입력한 내용이 이번 주 설교가 되고, 기존 이번 주 설교는 자동으로 지난 설교 목록에 보관됩니다.
지난 설교로 추가: 이번 주 설교는 그대로 두고, 입력한 내용을 지난 설교 목록에만 추가합니다 (옛날 설교 직접 등록할 때 사용).

📚 지난 설교

"이번 주 설교"가 새로 저장될 때 자동으로 여기에 보관됩니다. 사용자 메인 페이지의 "지난 설교" 섹션에 표시됩니다.
